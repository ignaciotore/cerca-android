# CERCA Web / PWA

Versión web instalable de CERCA, separada de la app Android nativa.

## Incluye
- Login, registro y recuperación de contraseña.
- Inicio con SOS normal y silencioso.
- Ubicación en vivo con watchPosition y mapa Leaflet/OpenStreetMap.
- Actualización de emergencia a la Red CERCA.
- Alertas entrantes y marcado como visto.
- Mi Red CERCA: invitaciones, aceptación por código y baja de vínculos.
- Información útil ante una emergencia.
- Perfil y cierre de sesión.
- PWA instalable en Android/iPhone.
- Service worker preparado para Web Push si el backend entrega configuración Web Push compatible.

## Backend
Usa el backend existente de CERCA en Supabase. La app Android actual no se modifica.


Deploy automático: Vercel / cerca-seguridad.
